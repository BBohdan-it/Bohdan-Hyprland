# SETUP
I use this:
- OS: NixOS
- WM: Hyprlnd
- Terminal: Kitty
- Bar: Waybar
- Notification: SwayNC
- Launcher: Rofi
- Shell: Zsh
- File Manager: Yazi
- Wallpaper app: Awww (swww)
- Greater: SDDM

# INSTALATION
Just clone my dots
```bash
git clone https://github.com/BBohdan-it/Bohdaan-Hyprland.git
cd Bohdan-Hyprland
```
